# Colores

Paleta oscura con acento hielo (ice). Valores canónicos en [`tokens.css`](tokens.css).

| Token | Hex / valor | Uso |
|-------|-------------|-----|
| `--bg` | `#0e1317` | Fondo principal |
| `--bg-elev` | `#192031` | Superficies elevadas |
| `--bg-deep` | `#080c0f` | Bandas profundas / footer |
| `--accent` | `#b8e1ec` | CTAs, highlights, énfasis |
| `--accent-2` | `#617a98` | Secundario / labels |
| `--ink` | `#0e1317` | Texto sobre accent |
| `--text` | `#ffffff` | Texto principal |
| `--text-muted` | `#cdc8c8` | Supporting copy |
| `--text-dim` | `#617a98` | Microcopy / hints |
| `--line` | `rgba(97,122,152,0.22)` | Bordes sutiles |
| `--star` | `#e6a400` | Estrellas de reviews |

## Uso

- CTAs primarios: fondo `--accent`, texto `--ink`.
- Highlights tipográficos (`.hl`): color `--accent`.
- Evitar púrpuras, glows genéricos o paletas ajenas al brand.
